# A walk into the connected garden

Start at the notebook cover, or open any stop. All controls work without animation. Numeric inputs provide an alternative to dragging.

1. **Multiplication:** numbers a + bj obey j² = p. Their product is (ac + pbd) + (ad + bc)j. Changing p changes the algebra.
2. **Derivative:** in dual numbers ε² = 0. Squaring a + bε gives a² + 2abε. With b = 1, the second slot equals the derivative of a². With b = 0, the slot is zero even when the derivative is not.
3. **Graph / map:** switch explicitly to ordinary complex numbers, i² = −1. The function z² sends each input to an output. Its graph keeps that pair in four real coordinates. The guided graph drops Im w and shows that omitted value numerically.
