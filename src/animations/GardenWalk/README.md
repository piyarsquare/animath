# Number planes notebook

A short, re-enterable walk through multiplication, a dual-number derivative, and the graph/map correspondence for z². Built from the connected-garden route spec in `docs/CONNECTED_GARDEN_ROUTE.md`.

Open `#/garden`, or enter directly at `#/garden?stop=multiplication`, `#/garden?stop=derivative`, or `#/garden?stop=graph`. Each instrument is usable on its own; the notebook provides an optional sequence.

Arithmetic is rendered with SVG and shared form controls. The third stop reuses the existing Complex Particles and Plane Transform engines. Its selected input and function agree across views. The full instruments offer a return to the notebook; changing functions there requires explicitly resuming the square passage.

This is a bounded adaptation of the Number Planes notebook ideas into the current workspace. It does not import the entire historical notebook branch or its unfinished rooms. There are no completion gates, saved investigation records, or cross-device state promises.
